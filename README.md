# 日本で検挙された外国人は、どこから来たか

警察庁「犯罪統計書」令和6年の外国人犯罪の表を、刑法犯と特別法犯に分けて見る。

- 想定URL: https://japan-foreigners-crime.visualizing.jp/
- 期間: 2015–2024年。年次表の範囲。
- 数: 検挙件数と検挙人員。人口あたりの率ではない。刑法犯と特別法犯は足さない。

```bash
npm install
npm run fetch
npm run normalize
npm run verify
npm run data
npm run dev
```
