年次表は2015年から2024年まで。刑法犯は交通業過を除く。特別法犯は交通法令違反を除く。

129表の注: 「来日外国人」とは、我が国にいる外国人のうち、いわゆる定着居住者（永住権を有する者等）、在日米軍関係者及び在留資格不明の者以外の者をいう。

132表・133表の注: 「中国」には台湾、香港等を含む。

国籍の構成を在留者数と比べるときの注は、警察白書令和7年版「来日外国人犯罪の検挙状況」。永住者、永住者の配偶者等、特別永住者を除いた在留外国人の国籍構成は国によって違う。https://www.npa.go.jp/hakusyo/r07/honbun/html/bb4432000.html

照合した令和6年の数: 刑法犯の検挙件数 18,861、検挙人員 10,464。来日の刑法犯 13,405件、6,368人。来日の特別法犯 8,389件、5,802人。
